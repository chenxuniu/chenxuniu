## Selected projects

- **[TokenPowerBench](https://github.com/chenxuniu/TokenPowerBench)**  
  Measures LLM inference power consumption across single-node and multi-node GPU settings, with separate metrics for prefill and decode.  
  [AAAI 2026 paper](https://doi.org/10.1609/aaai.v40i38.40535)

- **[LLM Inference Engine Benchmark](https://github.com/chenxuniu/LLM-Inference-Engine-Benchmark)**  
  Benchmarks energy consumption and efficiency across vLLM, TensorRT-LLM, DeepSpeed, and Transformers.  
  [HotCarbon 2025 paper](https://doi.org/10.1145/3757892.3757900)

- **[llm-power-profiler](https://github.com/chenxuniu/llm-power-profiler)**  
  A lightweight local monitor for watts, tokens, and joules per token on OpenAI-compatible LLM servers.
